# 09 — 表单与校验规范

> 基于 Wot UI v2 Form 组件、async-validator 校验模式，参考 TDesign / NutUI 表单最佳实践制定。

## 技术选型

- **表单组件**：Wot UI v2 的 `wd-form` + `wd-form-item`
- **校验引擎**：async-validator（Wot UI v2 内置）
- **状态管理**：页面内 `reactive` 管理表单数据

## 表单结构约定

```vue
<template>
  <wd-form :model="form" :rules="rules" ref="formRef" label-width="180rpx">
    <!-- 标题 -->
    <wd-form-item label="标题" prop="title">
      <wd-input v-model="form.title" placeholder="请输入标题" clearable maxlength="50" />
    </wd-form-item>

    <!-- 分类 -->
    <wd-form-item label="分类" prop="category">
      <wd-input v-model="form.category" placeholder="请输入分类" clearable maxlength="30" />
    </wd-form-item>

    <!-- 提交按钮 -->
    <view class="mt-8 px-6">
      <wd-button type="primary" block :loading="submitting" @click="handleSubmit"> 提交 </wd-button>
    </view>
  </wd-form>
</template>

<script setup lang="ts">
import { reactive, ref } from "vue"
import { useI18n } from "vue-i18n"
import type { FormInstance, FormRules } from "@wot-ui/ui"

const { t } = useI18n()

// ===== 表单数据 =====
const form = reactive({
  title: "",
  category: "",
  email: "",
  content: "",
})

// ===== 表单引用 =====
const formRef = ref<FormInstance>()
const submitting = ref(false)

// ===== 校验规则 =====
const rules: FormRules = {
  title: [
    { required: true, message: t("validation.required"), trigger: "blur" },
    { min: 2, max: 50, message: "标题长度为 2-50 个字符", trigger: "blur" },
  ],
  category: [
    { required: true, message: t("validation.required"), trigger: "blur" },
    { min: 1, max: 30, message: "分类长度为 1-30 个字符", trigger: "blur" },
  ],
  email: [{ type: "email", message: t("validation.emailInvalid"), trigger: "blur" }],
}

// ===== 提交 =====
async function handleSubmit() {
  if (submitting.value) return

  try {
    // 1. 表单校验
    await formRef.value?.validate()

    // 2. 业务校验（可选）
    // ...

    // 3. 提交
    submitting.value = true
    await submitForm({ ...form })

    // 4. 成功处理
    uni.showToast({ title: "提交成功", icon: "success" })
    setTimeout(() => uni.navigateBack(), 1500)
  } catch (err) {
    // 校验失败或业务错误
    if (err instanceof Error && err.message) {
      uni.showToast({ title: err.message, icon: "none" })
    }
  } finally {
    submitting.value = false
  }
}
</script>
```

## 校验规则编写规范

### 内置校验类型

| type      | 说明           | 示例                                                   |
| --------- | -------------- | ------------------------------------------------------ |
| `string`  | 字符串（默认） | `{ type: 'string', min: 2, max: 20 }`                  |
| `number`  | 数字           | `{ type: 'number', min: 0, max: 100 }`                 |
| `boolean` | 布尔值         | `{ type: 'boolean' }`                                  |
| `email`   | 邮箱           | `{ type: 'email' }`                                    |
| `array`   | 数组           | `{ type: 'array', min: 1, message: '请至少选择一项' }` |
| `date`    | 日期           | `{ type: 'date' }`                                     |
| `url`     | URL            | `{ type: 'url' }`                                      |

### 校验触发时机

| trigger               | 触发时机   | 适用场景               |
| --------------------- | ---------- | ---------------------- |
| `blur`                | 失焦时     | 输入框、文本域         |
| `change`              | 值变化时   | 选择器、开关、日期选择 |
| `'blur'` + `'change'` | 两者都触发 | 重要字段               |

### 自定义校验器

```ts
/**
 * URL 校验
 */
function validateUrl(value: string): boolean | Error {
  if (!value) return true // 必填由 required 控制
  try {
    new URL(value)
    return true
  } catch {
    return new Error("请输入正确的 URL")
  }
}
```

**规则**：

1. 自定义校验器返回 `true` 表示通过，返回 `Error` 表示失败。
2. 非必填字段的空值校验由 `required: false` 控制，自定义校验器中空值直接返回 true。
3. 校验错误消息走 i18n（如 `t('validation.emailInvalid')`）。

## 常用校验函数库

在 `src/utils/validate.ts` 中统一维护：

```ts
// utils/validate.ts

/** 手机号 */
export function isPhone(value: string): boolean {
  return /^1[3-9]\d{9}$/.test(value)
}

/** 邮箱 */
export function isEmail(value: string): boolean {
  return /^[\w-]+(\.[\w-]+)*@[\w-]+(\.[\w-]+)+$/.test(value)
}

/** URL */
export function isUrl(value: string): boolean {
  try {
    new URL(value)
    return true
  } catch {
    return false
  }
}
```

## 表单布局规范

### 标签宽度

- 移动端标准：`label-width="180rpx"`（约 90px）
- 短标签表单：`label-width="140rpx"`
- 无标签：`label-width="0"` 或不用 label

### 必填标识

```vue
<wd-form-item label="标题" required>
  <!-- content -->
</wd-form-item>
```

红色 `*` 号由 `required` 属性自动渲染。

### 表单分组

长表单用 `wd-cell-group` 或自定义分组标题分组：

```vue
<!-- 基本信息 -->
<view class="text-lg font-medium text-ink mt-6 mb-3 px-6">基本信息</view>
<wd-form :model="form" :rules="rules">
  <!-- ... -->
</wd-form>

<!-- 扩展信息 -->
<view class="text-lg font-medium text-ink mt-8 mb-3 px-6">扩展信息</view>
<wd-form :model="form" :rules="rules">
  <!-- ... -->
</wd-form>
```

## 表单状态管理

### 编辑表单

```ts
// 页面加载时获取详情，填充表单
onLoad(async (options) => {
  if (options.id) {
    loading.value = true
    try {
      const detail = await getResourceDetail(options.id)
      Object.assign(form, detail) // 用 Object.assign 保持响应式
    } finally {
      loading.value = false
    }
  }
})
```

### 表单重置

```ts
function resetForm() {
  formRef.value?.resetFields()
  // 或手动重置
  Object.assign(form, getInitialForm())
}
```

## 复杂表单模式

### 动态表单字段

使用 `v-for` 渲染动态字段：

```vue
<view v-for="(item, index) in form.items" :key="index">
  <wd-form-item :label=`条目${index + 1}标题` :prop=`items.${index}.title`>
    <wd-input v-model="item.title" />
  </wd-form-item>
</view>

<wd-button plain @click="addItem">添加条目</wd-button>
```

### 表单联动

用 `watch` 或 `computed` 处理字段联动：

```ts
// 选择分类后自动填充默认描述
watch(
  () => form.category,
  (category) => {
    if (!form.content && category) {
      form.content = `${category} 的默认描述`
    }
  }
)
```

## 提交按钮规范

1. **位置**：表单底部，距表单内容至少 32rpx 间距，页面左右 48rpx 边距。
2. **样式**：全宽主按钮（`type="primary" block`）。
3. **加载态**：提交过程中显示 loading，禁用重复点击。
4. **禁用态**：表单必填项未填时禁用按钮（可选，看产品需求）。
5. **点击反馈**：成功/失败都有明确反馈（Toast + 跳转/停留在页面）。

## 表单无障碍

1. 每个输入框都有关联的 label。
2. 必填字段有 `*` 标识。
3. 错误提示清晰可读，颜色对比度达标。
4. 键盘类型匹配输入类型（如数字输入使用数字键盘）。

## 常见坑

1. **小程序端表单校验不触发**：检查 `prop` 是否与 `form` 中的字段名一致，且 `wd-form-item` 在 `wd-form` 内部。
2. **数字类型字段校验异常**：`wd-input` 的 `type="number"` 返回的是 string，校验时注意类型转换。
3. **async-validator 不支持小程序**：Wot UI v2 已做适配，直接用即可。
4. **表单数据与详情数据结构不一致**：建议定义统一的类型，避免字段错位。
