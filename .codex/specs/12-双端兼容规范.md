# 12 — 双端兼容规范（H5 + 微信小程序）

> 基于 uni-app 跨端原理、微信小程序与 H5 的差异点，以及高星 uni-app 项目的踩坑经验总结。

## 核心原则

1. **双端一致优先**：优先使用 uni-app 提供的跨端 API 和组件，避免平台特定实现。
2. **差异隔离**：平台差异通过条件编译或平台判断封装，业务代码不感知。
3. **双端验证**：每个功能必须在 H5 和微信小程序两端都验证通过。

## 条件编译

### 使用场景

条件编译 `#ifdef` / `#ifndef` 只用于处理平台差异，**不用于区分角色**（角色差异走运行时 store 判断）。

### 支持的平台

```
#ifdef H5          // 仅 H5
#ifdef MP-WEIXIN   // 仅微信小程序
#ifndef H5         // 除 H5 外
#ifndef MP-WEIXIN  // 除微信小程序外
```

### 代码中的条件编译

#### JS / TS 中

```ts
// #ifdef H5
import { h5SpecificFunc } from "./h5-utils"
// #endif

function doSomething() {
  // #ifdef MP-WEIXIN
  uni.setStorageSync("key", value)
  // #endif
  // #ifdef H5
  localStorage.setItem("key", value)
  // #endif
}
```

#### 模板中

```vue
<template>
  <view>
    <!-- #ifdef H5 -->
    <button @click="copyText">复制</button>
    <!-- #endif -->
    <!-- #ifdef MP-WEIXIN -->
    <button open-type="share">分享</button>
    <!-- #endif -->
  </view>
</template>
```

#### 样式中

```scss
.container {
  /* #ifdef H5 */
  cursor: pointer;
  /* #endif */
}
```

### 条件编译使用原则

1. **尽量少用**：能用 uni-app 跨端 API 实现的就不用条件编译。
2. **集中管理**：平台差异代码尽量封装在工具函数或组件中，业务代码不出现条件编译。
3. **成对出现**：一个平台的特殊逻辑，另一个平台要有对应的降级或替代方案。
4. **标注清晰**：条件编译块前后加注释说明为什么需要平台差异。

## 平台差异封装模式

### 工具函数封装

```ts
// utils/platform.ts

/**
 * 复制文本到剪贴板
 * 双端封装：H5 用 Clipboard API，小程序用 uni.setClipboardData
 */
export function copyText(text: string): Promise<void> {
  // #ifdef H5
  if (navigator.clipboard) {
    return navigator.clipboard.writeText(text)
  }
  // 降级方案
  const textarea = document.createElement("textarea")
  textarea.value = text
  document.body.appendChild(textarea)
  textarea.select()
  document.execCommand("copy")
  document.body.removeChild(textarea)
  return Promise.resolve()
  // #endif

  // #ifdef MP-WEIXIN
  return new Promise((resolve, reject) => {
    uni.setClipboardData({
      data: text,
      success: () => resolve(),
      fail: (err) => reject(err),
    })
  })
  // #endif
}
```

### 组件封装

```vue
<!-- components/feedback/ShareButton.vue -->
<template>
  <!-- #ifdef MP-WEIXIN -->
  <button open-type="share" class="share-btn">
    <slot>分享</slot>
  </button>
  <!-- #endif -->
  <!-- #ifdef H5 -->
  <button class="share-btn" @click="handleH5Share">
    <slot>分享</slot>
  </button>
  <!-- #endif -->
</template>

<script setup>
// #ifdef H5
function handleH5Share() {
  // H5 分享逻辑（生成链接 / 调用原生分享等）
}
// #endif
</script>
```

## 常见双端差异对照表

### API 差异

| 功能     | uni-app 跨端 API       | H5 特有                    | 小程序特有                    |
| -------- | ---------------------- | -------------------------- | ----------------------------- |
| 路由跳转 | `uni.navigateTo` 等    | —                          | `wx.navigateTo`（不要直接用） |
| 本地存储 | `uni.setStorageSync`   | `localStorage`             | `wx.setStorageSync`           |
| 网络请求 | `uni.request`          | `fetch` / `axios`          | `wx.request`                  |
| 剪贴板   | `uni.setClipboardData` | `navigator.clipboard`      | `wx.setClipboardData`         |
| 分享     | —                      | 自定义实现                 | `onShareAppMessage`           |
| 支付     | `uni.requestPayment`   | 微信/支付宝 JSAPI          | `wx.requestPayment`           |
| 扫码     | `uni.scanCode`         | 自定义实现                 | `wx.scanCode`                 |
| 定位     | `uni.getLocation`      | `navigator.geolocation`    | `wx.getLocation`              |
| 图片选择 | `uni.chooseImage`      | 原生 `<input type="file">` | `wx.chooseMedia`              |

### 组件差异

| uni-app 组件    | H5 渲染        | 小程序渲染      | 注意点                           |
| --------------- | -------------- | --------------- | -------------------------------- |
| `<view>`        | `<div>`        | `<view>`        | 布局主力                         |
| `<text>`        | `<span>`       | `<text>`        | 文本必须放 text 内（小程序限制） |
| `<image>`       | `<img>`        | `<image>`       | 小程序默认 320x240，注意 mode    |
| `<scroll-view>` | `<div>` + 滚动 | `<scroll-view>` | 小程序需设高度                   |
| `<swiper>`      | 自定义实现     | `<swiper>`      | 轮播图                           |
| `<button>`      | `<button>`     | `<button>`      | 小程序有 open-type               |
| `<input>`       | `<input>`      | `<input>`       | type 值有差异                    |

### 样式差异

| 特性               | H5   | 小程序         | 解决方案                           |
| ------------------ | ---- | -------------- | ---------------------------------- |
| 通配选择器 `*`     | 支持 | 不支持         | 不用 `*`                           |
| 属性选择器         | 支持 | 不支持         | 不用属性选择器                     |
| `:hover` 伪类      | 支持 | 不支持         | 用 `hover-class`                   |
| `::before/::after` | 支持 | 部分支持       | 谨慎使用                           |
| `position: fixed`  | 支持 | 支持但有坑     | 小程序端避开 input 聚焦时          |
| `vh` / `vw` 单位   | 支持 | 支持           | 统一用 rpx                         |
| 背景图本地         | 支持 | 不支持         | 用 `<image>` 或 base64             |
| `z-index`          | 正常 | 原生组件层级高 | 避开 video、map、canvas 等原生组件 |

## 小程序特有能力

### 分享

```ts

onShareAppMessage(() => {
  return {
    title: "应用名称",
    path: "/pages/index/index",
  }

onShareTimeline(() => {
  return {
    title: "应用名称",
  }

```

### 小程序码 / 扫码

```ts
// 扫码
function scanQRCode() {
  uni.scanCode({
    onlyFromCamera: false,
    scanType: ["qrCode"],
    success: (res) => {
      const code = res.result
      // 处理扫码结果
    },
```

### 订阅消息

小程序订阅消息功能，需条件编译隔离：

```ts
// #ifdef MP-WEIXIN
function requestSubscribe(tmplIds: string[]) {
  return new Promise((resolve, reject) => {
    uni.requestSubscribeMessage({
      tmplIds,
      success: resolve,
      fail: reject,
    })
  })
}
// #endif
```

## H5 特有注意事项

### 移动端适配

1. **viewport 设置**：已在 `index.html` 中配置，禁止修改。
2. **点击延迟**：uni-app H5 已处理 300ms 点击延迟。
3. **软键盘弹起**：input 聚焦时页面调整，用 `onKeyboardHeightChange` 监听。

### 浏览器兼容性

目标浏览器：iOS 12+、Android 6+、Chrome 70+。

- 不使用太新的 JS API（如 `structuredClone`），必要时 polyfill。
- CSS 用 UnoCSS，自动处理浏览器前缀。

### 路由模式

H5 端默认 hash 模式（`#/pages/index/index`），如需 history 模式需后端配合配置。

## 平台判断运行时

条件编译是编译期的，如需运行时判断平台：

```ts
// utils/platform.ts
export function isH5(): boolean {
  // #ifdef H5
  return true
  // #endif
  // #ifndef H5
  return false
  // #endif
}

export function isMP(): boolean {
  // #ifdef MP-WEIXIN
  return true
  // #endif
  // #ifndef MP-WEIXIN
  return false
  // #endif
}
```

> 优先用条件编译（编译期剔除，体积更小），运行时判断只在动态场景使用。

## 双端测试清单

每个功能开发完成后，逐项验证：

1. 页面布局在 H5 和小程序中是否一致
2. 文字是否都在 `<text>` 标签内（小程序中不支持 view 直接选中文本）
3. 图片 mode 是否正确设置
4. 交互事件在两端都正常触发
5. 网络请求在两端都正常（含跨域/H5 代理）
6. 本地存储读写正常
7. 分享/支付等平台特有功能是否有降级方案
8. 列表滚动是否流畅
9. 表单输入和键盘行为是否正常
10. 状态栏/导航栏适配是否正确

## 常见坑

1. **小程序 text 标签限制**：文本选择、换行等只在 `<text>` 中有效，不要把文本直接放 `<view>`。
2. **小程序 image 默认尺寸**：未设置宽高时默认 320x240px，必须显式设置或用 mode。
3. **H5 跨域**：开发环境用 Vite proxy，生产环境用 Nginx 反向代理或 CORS。
4. **小程序包体积**：主包 2MB 限制，注意分包和资源压缩。
5. **小程序自定义 tabBar**：与 easycom 配合时注意组件路径正确。
6. **H5 路由参数**：H5 端 URL 参数在刷新后仍可用，小程序端只在 onLoad 时获取。
